# 项目简介

## 项目名称

苏品智航 / Jiangsu ExportPilot

## 赛道背景

本项目用于江苏高校“丝路电商”创新挑战赛 OPC 智能体应用赛道。比赛关注跨境电商、产业带出海、智能体应用和数据驱动的商业决策能力。

江苏制造企业拥有丰富的产业带资源，但中小企业在海外市场选择、竞品洞察、本地化营销、数据整合和报告制作方面通常缺少低成本工具。本项目以 AI 智能体为核心，把公开数据、企业产品信息和大模型分析整合为一个可演示的平台。

## 目标用户

- 江苏制造企业外贸负责人
- 跨境电商运营团队
- 产业带服务机构
- 高校创新创业团队
- 比赛评审与演示观众

## 核心价值

- 帮助企业快速判断产品适合进入哪些海外市场。
- 将公开 API、CSV 样本和 AI 分析统一到一个可解释的工作流。
- 用可视化看板展示市场机会、风险、竞品与内容趋势。
- 生成适合比赛演示和企业初步决策的出海分析报告。

## 核心功能

- 企业产品信息录入：产品名称、品类、材料、价格区间、目标市场、产地优势等。
- CSV 样本数据导入：在外部 API 不稳定或无 Key 时提供可演示数据。
- 外部数据源接入：当前 runtime 覆盖 World Bank、GDELT、UN Comtrade、YouTube、Etsy 和 CSV fallback；eBay、Rakuten、Reddit 保留为 P2 future provider。
- 阿里云百炼分析：使用 `qwen3.6-plus` 生成洞察、评分解释和营销建议。
- 市场机会评分：综合需求、竞争、宏观环境、内容热度、贸易数据和风险因素。
- 营销文案生成：生成英文或目标市场本地化的标题、卖点、广告文案和社媒内容草稿。
- 可视化看板：展示评分、趋势、国家对比、平台信号和 AI 摘要。
- 出海报告生成：输出结构化 Markdown/HTML 报告并支持复制/预览；PDF 导出保留为 v1 后续增强。

## MVP 范围

MVP 必须支持：

- 本地 Docker Compose 启动前端、后端和 PostgreSQL。
- 手动录入至少一种江苏制造产品。
- 导入样例 CSV 数据，并在无外部 API Key 时完成完整演示。
- 后端统一封装外部数据源和 AI 调用。
- 生成市场机会评分和可解释理由。
- 前端展示产品、目标市场、评分、图表和 AI 洞察。
- 生成一份可预览、可复制的出海报告；PDF 下载不作为当前 MVP 验收条件。
- 管理页显示各 API Key 的“已配置/未配置”状态，不显示明文。

## 非 MVP 范围

- 不做真实支付、订单、物流、库存和客户关系管理。
- 不承诺所有外部 API 在比赛现场实时可用，必须保留 CSV fallback。
- 不保存真实企业敏感资料。
- 不把 AI 输出作为法律、关税或投资建议。
- 不在前端直接调用第三方平台 API。
