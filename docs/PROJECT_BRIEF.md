# 项目简介

## 项目名称

苏品智航 / Jiangsu ExportPilot

## 赛道背景

本项目用于江苏高校“丝路电商”创新挑战赛 OPC 智能体应用赛道。比赛关注跨境电商、产业带出海、智能体应用和数据驱动的商业决策能力。

江苏制造企业拥有丰富的产业带资源，但中小企业在海外市场选择、竞品洞察、本地化营销、数据整合和报告制作方面通常缺少低成本工具。本项目以 AI 智能体为核心，把公开数据、企业产品信息和大模型分析整合为一个可演示的平台。

## 目标用户

- 江苏制造企业外贸负责人
- 跨境电商运营团队
- 产业带服务机构
- 高校创新创业团队
- 比赛评审与演示观众

## 核心价值

- 帮助企业快速判断产品适合进入哪些海外市场。
- 降低企业与产品资料整理门槛，支持从手动录入、CSV、多图商品录入、单个商品链接和企业资料拍照生成可确认的草稿。
- 将公开 API、CSV 样本和 AI 分析统一到一个可解释的工作流。
- 用可视化看板展示市场机会、风险、竞品与内容趋势。
- 生成适合比赛演示和企业初步决策的出海分析报告。

## 核心功能

- 企业产品信息录入：产品名称、品类、材料、价格区间、目标市场、产地优势等。
- CSV 样本数据导入：在外部 API 不稳定或无 Key 时提供可演示数据。
- 智能商品导入：支持用户上传淘宝、拼多多、京东商品详情页截图或企业产品目录截图，也支持用户主动粘贴单个商品链接；后端调用 Qwen 视觉/多模态能力生成 `product_drafts`，用户确认后才写入正式产品库。
- 多图商品录入：下一轮升级支持同一产品上传多张图片，包括商品主图、详情页、包装、规格表、资质材料或产品目录页；系统只先生成 `product_drafts`，用户确认后才进入正式产品库和分析流程。
- 拍照快速新增企业：下一轮升级支持用户拍摄营业执照、企业名片、展会资料或产品目录封面，由后端生成 `company_drafts`，用户确认后才写入正式企业库。
- 外部数据源接入：当前 runtime 覆盖 World Bank、GDELT、UN Comtrade、YouTube、Etsy 和 CSV fallback；eBay、Rakuten、Reddit 保留为 P2 future provider。
- 阿里云百炼分析：使用 `qwen3.6-plus` 生成洞察、评分解释和营销建议。
- 市场机会评分：综合需求、竞争、宏观环境、内容热度、贸易数据和风险因素。
- 五大洲市场分析与更多市场区扩展：目标国家从固定少量国家扩展为后端国家库和市场区域目录管理，覆盖五大洲并支持北美、欧洲、东亚、东南亚、南亚、中东、非洲、拉美、澳新等市场区域；前端只消费后端目录，不写死国家列表。
- 营销文案生成：生成英文或目标市场本地化的标题、卖点、广告文案和社媒内容草稿。
- 可视化看板：展示评分、趋势、国家对比、平台信号和 AI 摘要。
- 全局 AI 聊天：下一轮升级提供跨页面聊天窗口，能读取当前企业、产品、分析结果和报告上下文，回答问题、解析报告并生成报告修改建议。
- 报告生成与版本管理：输出结构化 Markdown/HTML 报告并支持复制/预览；聊天修改报告只生成 proposal，用户确认后保存为新报告版本，原版本保留；PDF 导出保留为 v1 后续增强。
- 前端整体优化：下一轮升级重排信息架构、导航、移动端拍照录入、分析目标选择、全局聊天入口和报告编辑体验，让演示主链路更集中。

## 下一轮产品升级方向

Q40 之后的产品升级围绕“更快录入、更广市场、更强报告协作”展开：

- 多图商品录入：一次导入允许多张商品图片，后端合并图片证据并生成 `product_drafts`，用户确认后才入库。
- 拍照建企业：企业资料图片先生成 `company_drafts`，用户确认后才创建正式企业记录。
- 五大洲与多市场区域分析：后端维护目标国家与市场区域目录，前端通过 API 获取可选国家、区域、默认组合和启停状态。
- 全局 AI 聊天：聊天窗口可解析报告、解释评分、定位报告段落和生成修改 proposal，但不得直接覆盖报告正文。
- 报告修改与版本管理：报告修改必须经过用户确认，确认后生成新版本并保留旧版本、来源报告、修改原因和 proposal 记录。

Q40 插件借鉴原则：

- 参考 `openai/role-specific-plugins` 只借鉴工作流方法，例如来源验证、证据记录、草稿/审阅/确认、报告 QA、source posture 和 UX 审查。
- 不复制插件实现、connector app id、`.app.json` workspace 绑定、MCP 配置、assets、scripts、templates、品牌素材或 marketplace 元数据。

## MVP 范围

MVP 必须支持：

- 本地 Docker Compose 启动前端、后端和 PostgreSQL。
- 手动录入至少一种江苏制造产品。
- 导入样例 CSV 数据，并在无外部 API Key 时完成完整演示。
- 后端统一封装外部数据源和 AI 调用。
- 生成市场机会评分和可解释理由。
- 前端展示产品、目标市场、评分、图表和 AI 洞察。
- 生成一份可预览、可复制的出海报告；PDF 下载不作为当前 MVP 验收条件。
- 管理页显示各 API Key 的“已配置/未配置”状态，不显示明文。

## 非 MVP 范围

- 不做真实支付、订单、物流、库存和客户关系管理。
- 不承诺所有外部 API 在比赛现场实时可用，必须保留 CSV fallback。
- 不保存真实企业敏感资料。
- 不把 AI 输出作为法律、关税或投资建议。
- 不在前端直接调用第三方平台 API。
- 不绕过淘宝、拼多多、京东等平台的登录、验证码、风控或访问限制。
- 不做国内平台商品的批量采集、搜索结果采集、店铺采集或后台定时抓取。
- 不承诺能解析所有国内商品链接；链接解析失败时必须提示用户改用截图上传。
- 不把截图或链接解析结果表述为平台官方验证数据。
