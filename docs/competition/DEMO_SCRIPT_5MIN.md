# 5 分钟比赛演示脚本

适用场景：江苏高校“丝路电商”创新挑战赛 OPC 智能体应用赛道现场演示。

演示前检查：

- 后端、前端、PostgreSQL、Redis 已启动。
- 如果要展示实时视觉识别，确认后端已配置 `DASHSCOPE_API_KEY` 或 `BAILIAN_API_KEY`、`BAILIAN_VISION_ENABLED=true` 和可用的 `BAILIAN_VISION_MODEL`。
- 如果视觉模型不可用，说明本轮使用低置信度人工草稿或样本兜底，不把它说成实时模型识别。
- 准备一张已裁剪的淘宝、拼多多、京东商品截图或企业产品目录截图，不包含订单号、手机号、地址、聊天记录、账号头像或其他隐私信息。

## 0:00-0:30 开场

讲解：

苏品智航面向江苏制造企业，解决产品资料整理、海外市场判断、竞品信号汇总、本地化营销和出海报告生成成本高的问题。系统把企业产品信息、公开 API、CSV 样本数据和 Qwen 分析组织成一个可解释的出海选品智能体流程。

操作：

- 打开首页或 `/products/import`。
- 简短指出导航中的产品、分析、看板、营销和报告模块。

## 0:30-1:20 商品截图导入

讲解：

企业可以上传用户主动提供的淘宝、拼多多、京东商品截图，或企业自己的产品目录截图。截图只作为产品信息整理材料，不代表平台官方验证。

操作：

1. 打开 `/products/import`。
2. 选择企业。
3. 保持“截图导入” Tab。
4. 选择来源平台：淘宝、拼多多或京东。
5. 上传已裁剪的商品截图。
6. 点击“开始识别”。

提示话术：

截图上传前必须裁剪隐私信息。系统不读取订单、聊天、账号或收货信息，只提取商品名称、价格参考、规格、材质、卖点和证据摘录。

## 1:20-2:00 Qwen 识别与人工确认

讲解：

后端调用 Qwen 视觉/多模态能力生成产品草稿，草稿包含字段、置信度、证据和风险提示。所有结果必须由用户确认后才写入正式产品库。

操作：

1. 展示草稿编辑区。
2. 指出产品名、类目、价格 CNY、材质、规格、卖点、英文关键词和 evidence。
3. 如需要，修改产品中文名或规格。
4. 点击“确认入库”。
5. 跳转到 `/products?company_id=...&product_id=...` 后展示产品列表中的新产品。

提示话术：

国内截图或链接中的价格只是国内页面参考价，不是海外售价、成交价、采购成本或利润依据。

## 2:00-3:10 海外市场机会分析

讲解：

确认入库后的产品可以进入出海分析流程。系统会围绕目标国家汇总公开 API、缓存、CSV 样本和 AI 分析结果，生成市场机会评分。

操作：

1. 打开 `/analysis/run`。
2. 选择刚确认的产品。
3. 选择目标国家，例如 US、JP、GB。
4. 使用推荐演示配置或手动设置竞品样本检索上限。
5. 点击开始分析。
6. 展示步骤日志：数据源、竞品样本、内容趋势、机会评分、营销和报告准备。

提示话术：

外部 API 不稳定或无 Key 时，CSV fallback 保证比赛现场可以完整演示。fallback 表示证据兜底，不表示流程失败。

## 3:10-4:00 看板洞察

讲解：

看板把分析结果变成可解释的决策视图，便于企业判断优先市场和产品机会。

操作：

1. 打开 `/dashboard/{analysis_id}`。
2. 展示国家推荐、产品机会评分、竞品价格区间、内容主题和风险卡片。
3. 指出每个图表下的数据来源说明。

提示话术：

海外机会评分基于海外竞品样本、内容趋势、国家市场画像和贸易数据。国内商品截图/链接只用于识别企业可供产品信息。

## 4:00-4:40 营销内容与报告

讲解：

系统可以把分析结果转成运营可用的英文标题、五点描述、短视频脚本和报告草稿。

操作：

1. 打开 `/marketing`，展示营销文案生成结果。
2. 打开 `/reports`，展示报告列表和详情页。
3. 展示报告中的数据源说明、风险提示和下一步行动计划。

提示话术：

报告适合比赛演示和企业初步决策，不是法律、关税、投资或财务建议。PDF 导出是 v1 后续增强，不作为当前 MVP 的完成项。

## 4:40-5:00 收束

讲解：

苏品智航的核心价值是把“产品录入、海外机会分析、营销生成、报告输出”连成一个人机协同闭环。系统坚持后端管理密钥、人工确认入库、公开数据和样本兜底，并且不绕过国内平台的登录、验证码或访问限制。

结束语：

这套方案帮助江苏制造企业更低成本地完成出海选品预研，把分散的数据和 AI 能力变成可解释、可复核、可演示的工作流。
