# 5 分钟比赛演示脚本

适用场景：江苏高校“丝路电商”创新挑战赛 OPC 智能体应用赛道现场演示。

演示目标：让评委在 5 分钟内看到苏品智航如何把“企业建档、商品录入、五大洲市场分析、报告解释、报告修改确认”串成一个可落地的出海预研工作流。

## 演示前检查

- 后端、前端、PostgreSQL、Redis 已启动。
- 线上地址 `https://opc.ankangyu.cn` 可访问，或本地 `http://localhost:3000` 可访问。
- 准备 2-4 张企业照片或资料截图，例如门头、展台、名片、产品目录；先裁剪手机号、地址、证件号、聊天记录等隐私信息。
- 准备 3-8 张商品图片或电商截图，覆盖主图、规格、材质、卖点和使用场景；不要包含订单、账号、聊天或收货信息。
- 如果实时视觉模型不可用，说明本轮使用低置信度草稿或样本兜底，不把它说成真实模型识别。
- 外部 API 缺 Key、限流或网络异常时，使用缓存和 CSV fallback 完成主流程。

## 0:00-0:25 开场

讲解：

苏品智航面向江苏制造企业，解决出海前期资料分散、市场判断成本高、报告产出慢的问题。系统把企业照片、商品多图、公开数据源、CSV 兜底和 Qwen 分析组织成一条可解释、可复核、可人工确认的工作流。

操作：

1. 打开首页。
2. 快速指出导航中的企业、产品、分析、看板、聊天和报告模块。

提示话术：

“我们强调的是企业预研辅助，不直接替代正式尽调。系统会给出处、置信度和风险边界，关键写入动作都需要用户确认。”

## 0:25-1:10 拍照新增企业

讲解：

很多制造企业没有完整的数字化资料。现场可以用企业照片或资料截图快速生成企业草稿，降低建档成本。

操作：

1. 打开 `/companies/import`。
2. 上传企业门头、展台、名片或产品目录截图。
3. 点击开始识别，展示企业草稿。
4. 指出企业名称、地区、行业、企业描述、主营产品、目标市场建议、置信度和 evidence。
5. 修改一个字段，例如主营产品或目标市场建议。
6. 点击确认，写入正式企业库。

提示话术：

“企业照片只是录入材料。AI 先给草稿，系统不会自动把识别结果当成正式档案，必须经过人工确认。”

## 1:10-2:00 多图录入商品

讲解：

单张截图容易漏掉规格、材质和使用场景。多图录入把主图、详情图、参数图和卖点图合并理解，可靠性比单图更高。

操作：

1. 打开 `/products/import`。
2. 选择刚确认的企业。
3. 选择截图或图片导入。
4. 上传 3-8 张商品图。
5. 点击开始识别。
6. 展示产品草稿中的产品名、类目、规格、材质、颜色、卖点、目标用户、英文关键词、风险提示和证据摘录。
7. 人工修正一个字段，例如规格或英文关键词。
8. 点击确认入库。

提示话术：

“国内页面价格只作为产品信息参考，不代表海外售价、成交价或利润判断。正式分析仍以目标市场数据、海外竞品样本和人工复核为准。”

## 2:00-3:05 五大洲市场分析

讲解：

商品确认后进入出海机会分析。系统从后端目标国家目录加载国家，支持覆盖五大洲的组合分析，并通过缓存和并发控制保证现场速度。

操作：

1. 打开 `/analysis/run`。
2. 选择刚创建的企业和商品。
3. 选择一组覆盖五大洲的国家，例如 `US`、`DE`、`JP`、`BR`、`AU`、`ZA`。
4. 使用推荐演示配置，保持竞品样本上限在可控范围。
5. 点击开始分析。
6. 展示步骤日志：市场画像、贸易样本、竞品样本、内容趋势、机会评分、营销和报告准备。

提示话术：

“如果某个外部接口临时不可用，系统会显示 fallback 来源并继续完成流程。这不是隐藏失败，而是比赛现场和企业预研都需要的稳定兜底。”

## 3:05-3:45 看板和报告

讲解：

分析完成后，看板把结果转成企业能看懂的决策视图：哪些国家先看、为什么、证据来自哪里、风险是什么。

操作：

1. 打开 `/dashboard/{analysis_id}`。
2. 展示国家推荐、机会评分、竞品价格区间、内容主题和风险卡片。
3. 打开 `/reports/{id}`。
4. 展示报告结构：摘要、市场判断、证据来源、风险复核、下一步行动。
5. 指出版本列表和当前版本。

提示话术：

“报告采用备忘录式结构：先给结论，再说明证据、风险边界和下一步动作。它是经营预研材料，不是法律、关税或财务意见。”

## 3:45-4:30 全局聊天解释报告

讲解：

评委或企业负责人可以直接问报告：推荐逻辑是什么、数据源是否可靠、哪些结论需要复核。

操作：

1. 打开全局聊天浮窗，或进入 `/chat`。
2. 输入：“请解释这份报告为什么优先推荐这些市场，并列出最需要人工复核的三点。”
3. 展示聊天回答中的报告引用、来源边界和风险提示。
4. 追问：“如果只给企业一周时间，下一步应该先做什么？”

提示话术：

“聊天读取的是当前报告和分析的脱敏上下文，不接触 API Key，也不会把企业上传图片或隐私信息原样暴露出来。”

## 4:30-4:55 聊天修改报告并保存版本

讲解：

聊天可以提出报告修改建议，但不会直接覆盖报告。它先生成 proposal，用户确认后才保存新版本。

操作：

1. 输入：“把报告的下一步行动改成更适合线下展会拜访客户的版本。”
2. 展示 proposal 卡片，指出建议修改范围和风险提示。
3. 点击应用修改。
4. 展示报告版本列表新增一个版本，旧版本仍保留。
5. 可选：拒绝另一条 proposal，说明拒绝不会产生新版本。

提示话术：

“这是防误改机制：AI 只建议，用户决定是否应用。每次确认都会留下版本链路，便于赛后复盘和企业内部审阅。”

## 4:55-5:00 收束

结束语：

苏品智航把企业资料、商品多图、五大洲市场数据、AI 解释和报告版本管理连成一个闭环。它帮助江苏制造企业用更低成本完成出海预研，同时保留人工确认、来源说明、fallback 兜底和安全边界。
