# 评委答辩问答

## 1. 苏品智航解决什么问题？

苏品智航帮助江苏制造企业把产品资料、公开市场数据、海外竞品样本、内容趋势和 AI 分析整合成一个出海选品流程。它降低产品整理、市场判断、营销草稿和报告制作成本，适合比赛演示和企业初步决策。

## 2. 它为什么是智能体应用？

系统不是单次问答，而是把企业画像、产品导入、数据源聚合、市场画像、竞品样本、内容趋势、机会评分、营销生成和报告输出组织为连续工作流。每一步都有输入、输出、来源说明和 fallback 处理。

## 3. Qwen 用在哪里？

Qwen 用于商品截图或链接文本的产品理解、产品关键词补全、评分解释、营销内容生成和报告草稿生成。所有第三方 Key 只由后端读取，前端不接触密钥。

## 4. 为什么不直接爬淘宝、京东、拼多多？

我们不做批量采集，不绕过登录、验证码、风控、签名校验或 App 私有接口。系统只处理用户主动提供的单张截图或单个商品链接；链接解析也只尝试公开可访问页面的基础信息。遇到登录、验证码、风控、超时或结构不可解析时，系统提示上传截图。

## 5. 商品截图识别可靠吗？

截图识别适合降低录入成本，但不能替代人工确认。系统展示置信度、证据摘录和风险提示；低置信度时要求用户补全。只有用户确认后，草稿才会写入正式产品库。

## 6. 如果链接解析失败怎么办？

系统返回 `needs_screenshot`，前端提示“请上传商品截图继续分析”。这不是失败中断，而是合规兜底：不使用 Cookie、登录态、验证码识别、代理池或模拟登录。

## 7. 国内商品价格能不能作为海外售价？

不能。国内截图或链接中的价格只作为产品信息完整度参考，不代表海外销售价格、成交价、采购成本或利润依据。海外价格判断仍基于海外竞品样本和目标市场数据。

## 8. 用户上传截图是否合规？

系统只接收用户主动上传的截图，并在前端提示裁剪订单号、手机号、地址、聊天记录和账号头像等隐私信息。后端限制文件类型和大小，保存到运行时目录，不提交 GitHub。识别结果只保留商品相关字段和最小证据摘录。

## 9. 如何防止 AI 编造销量、认证或平台结论？

Prompt 和报告生成规则要求只使用结构化输入和证据字段，不得编造销量、评价、认证、排名或平台官方验证。报告也会补充来源边界和风险提示，把结论定义为方向性分析。

## 10. 外部 API 不可用时怎么办？

World Bank、GDELT、YouTube、Etsy、UN Comtrade 等数据源都有缓存或 CSV fallback。比赛现场即使没有 Key、额度不足或网络异常，也可以完成企业、产品、分析、看板、营销和报告主流程。

## 11. eBay、Rakuten、Reddit 是否已经接入？

它们是 P2 future provider，不作为当前 MVP 的真实 runtime 能力。演示和报告中不会把它们描述为本次真实调用来源。

## 12. 数据源是否等于官方结论？

不是。公开 API、公开页面基础信息、海外竞品样本和 CSV fallback 都是方向性证据。系统强调来源、fallback 状态和人工复核，不把结果说成平台官方验证、法律意见或投资建议。

## 13. 如何保护 API Key？

所有 Key 只写入服务器 `.env` 或部署密钥配置，并只由后端读取。前端只能看到“configured/not configured”等状态，不显示明文、掩码、长度或哈希。日志、截图、报告和异常中不得出现 Key、Token、Cookie 或 Authorization 头。

## 14. 这个系统能直接指导企业投放预算吗？

不能直接替代商业尽调。它提供低成本、可解释的预研结果。正式投放前还需要核验实时竞品、认证要求、物流成本、税费政策、广告预算和本地合规要求。

## 15. 当前 MVP 不包含什么？

当前 MVP 不包含支付、订单、库存、物流、CRM、PDF 完整导出、批量商品采集、店铺采集、搜索结果采集、保证所有外部 API 实时可用，或对法律、关税、投资收益作确定性判断。
