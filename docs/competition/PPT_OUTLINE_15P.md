# 15 页路演 PPT 大纲

## 1. 标题页

- 标题：苏品智航 / Jiangsu ExportPilot
- 副标题：面向江苏制造企业的 AI 出海选品与海外市场洞察智能体
- 展示：项目 Logo、团队名、赛道名

## 2. 赛道背景与目标用户

- 江苏制造企业拥有产业带和供应链优势。
- 目标用户：外贸负责人、跨境电商运营团队、产业带服务机构、高校创新创业团队。
- 比赛场景：丝路电商、跨境出海、智能体应用。

## 3. 企业痛点

- 产品资料分散，录入成本高。
- 不知道哪个海外市场更适合。
- 竞品价格、内容趋势和贸易数据难整合。
- 营销文案和报告制作耗时。
- 外部 API、AI 和样本数据缺少统一工作流。

## 4. 解决方案总览

- 一站式流程：产品导入、市场分析、看板洞察、营销生成、报告输出。
- 支持手动录入、CSV 样本、截图导入和单链接解析。
- 人工确认后才写入正式产品库。

## 5. 端到端工作流

- 用户上传截图或输入单个商品链接。
- Qwen 生成产品草稿。
- 用户确认产品。
- 系统运行海外市场机会分析。
- 输出营销内容和出海报告。

## 6. 数据与 AI 架构

- 前端：Next.js、TypeScript、Tailwind CSS、ECharts。
- 后端：FastAPI、Pydantic、SQLAlchemy、PostgreSQL。
- AI：Alibaba Cloud Bailian/Qwen。
- 数据源：World Bank、GDELT、YouTube、Etsy、UN Comtrade、CSV fallback。

## 7. 智能商品导入入口

- 截图占位：`/products/import` 页面。
- 展示截图导入 Tab 和链接导入 Tab。
- 强调只处理用户主动提供的材料。

## 8. 截图识别与产品草稿

- 截图占位：上传淘宝、拼多多、京东或企业目录截图后的草稿页。
- 展示字段：产品名、类目、价格参考、材质、规格、卖点、关键词、置信度、evidence。
- 说明截图识别是辅助录入，不是平台官方验证。

## 9. 人工确认与合规边界

- 截图占位：草稿编辑和确认入库。
- 关键点：低置信度提示、人工编辑、确认后写入产品库。
- 价格边界：国内参考价不作为海外售价、成交价、采购成本或利润依据。

## 10. 出海分析智能体流程

- 截图占位：`/analysis/run`。
- 展示步骤日志：数据采集、市场画像、竞品样本、内容趋势、评分、营销、报告准备。
- 说明 fallback 保证比赛现场可演示。

## 11. 市场洞察看板

- 截图占位：`/dashboard/{analysis_id}`。
- 展示 ECharts 图表：产品评分、国家推荐、竞品价格区间、内容主题。
- 强调数据来源和 fallback 状态可解释。

## 12. 营销文案生成

- 截图占位：`/marketing`。
- 展示英文标题、五点描述、短视频脚本、Pinterest 关键词和平台建议。
- 说明文案是草稿，正式发布前需要人工审核。

## 13. 出海报告预览

- 截图占位：`/reports/{id}`。
- 展示报告结构：企业画像、产品清单、数据源说明、市场概览、评分、竞品价格、内容趋势、推荐理由、风险提示、下一步行动。
- 说明 PDF 导出是 v1 后续增强。

## 14. 安全、fallback 与合规

- API Key 仅后端读取，前端不暴露。
- 上传截图保存在运行时目录，不提交 GitHub。
- 单链接解析不使用登录态、Cookie、验证码服务、代理池或模拟登录。
- 外部 API 失败时使用缓存或 CSV fallback。
- 报告不构成法律、关税、投资或财务建议。

## 15. 路线图与收束价值

- 短期：完善演示数据、部署稳定性、更多报告导出能力。
- 中期：接入 eBay、Rakuten、Reddit 等 P2 provider。
- 长期：连接更多产业带数据和企业内部产品库。
- 收束：让江苏制造企业用更低成本完成出海选品预研和营销准备。

## 截图使用要求

- 只使用演示账号和脱敏样本。
- 不展示真实 API Key、Cookie、Authorization 头、数据库连接串或管理员密码。
- 不展示订单号、手机号、地址、聊天记录、账号头像等隐私信息。
- 不把截图识别或单链接解析描述为平台官方验证。
