# 演示材料入口

Q16 后，比赛演示材料以 `docs/competition/` 为准，避免同一脚本在多个目录重复维护。

推荐阅读顺序：

1. `docs/competition/DEMO_SCRIPT_5MIN.md`：5 分钟现场演示脚本。
2. `docs/competition/JUDGES_QA.md`：评委答辩问答和合规话术。
3. `docs/competition/PPT_OUTLINE_15P.md`：15 页路演 PPT 大纲。

演示截图要求：

- 使用脱敏截图或样本数据。
- 不展示 API Key、Cookie、Authorization 头、数据库连接串或管理员密码。
- 不展示订单号、手机号、地址、聊天记录、账号头像等隐私信息。
- 不把截图识别或单链接解析说成平台官方验证。
